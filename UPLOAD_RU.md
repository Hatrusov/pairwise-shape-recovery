# Загрузка материалов в GitHub

Распакуйте архив и загрузите содержимое корневой папки репозитория, включая src, tests, revision, configs и .github. Не загружайте .venv и кэши.

Предпочтительно обновить существующий pairwise-shape-recovery и создать релиз v0.2.0: сохранится связь с прежним релизом v0.1.0. Описание релиза находится в RELEASE_NOTES.md. Если создаёте отдельный репозиторий, замените адреса в CITATION.cff и pyproject.toml фактическими адресами.

Выполните команды README.md и дождитесь успешных тестов GitHub Actions. После публикации добавьте действительный адрес релиза в Data availability statement. Сейчас рукопись ссылается на приложенные материалы, а не на ещё не опубликованный релиз.

Приложите этот ZIP к подаче в журнал как вычислительные дополнительные материалы. Он воспроизводит новые таблицы 6–7 и проверку восстановления C. Содержит статистики всех 75 000 повторений и все целочисленные контрпримеры. Исходные инженерные данные не распространяются; прежние таблицы 4–5 этим запуском не воспроизводились. Бутстреп и доверительные интервалы не моделировались.
